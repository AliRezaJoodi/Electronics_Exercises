## Capacitive Power Supply
Note: $Xc={{1\over 2πfC}}$ (`f` is frequency and `C` is the capacitance)  

F=50Hz, C=470nF => Xc=6K77  
F=50Hz, C=680nF => Xc=4K68  
F=50Hz, C=1uF => Xc=3K18
