## Buck DC-DC Converter, Isolated, Asynchronous, Based on LT3844

### Features, v1.0
- **Isolated Output:** 5V/5W
- **Non-Isolated Output:** 5V/5W
- **Input:** 12V
- **Asynchronous**
- **Controller:** PWM controller based on LT3844
