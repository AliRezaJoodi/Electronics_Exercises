## Boost DC-DC Converter, Non-Isolated, Synchronous, Based on LT8710
Note: Default applications of datasheet.  
Note: An exercise to understand the DC-DC converter.  

### Features
- **Output:** 12V/70W
- **Input:** 4.5V to 9V
- **Peak Current Mode Control**
- **Controller IC:** LT8710
