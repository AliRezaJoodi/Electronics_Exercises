## Buck-Boost DC-DC Converter, Non-Isolated, Non-Inverting, Non-Synchronous, 2-Switch, Base on LT8711
Note: Default applications from LTspice for exercise

### Features
- **Output:** 12W/15W
- **Input:** 7V to 40V
- **Peak Current Mode Control**
- **Controller:** LT8711
