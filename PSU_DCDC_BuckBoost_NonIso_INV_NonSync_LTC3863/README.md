## Buck-Boost DC-DC Converter, Non-Isolated, Inverting, Non-Synchronous, Base on LTC3863
Note: The design is from the datasheet.  

### Features
- **Output:** -5V/10W
- **Input:** 7V to 16V
- **Peak Current Mode Control**
- **Controller:** LTC3863
