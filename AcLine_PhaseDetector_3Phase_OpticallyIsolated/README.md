## Phase Detector, 3-Phase, Optically Isolated

### Features, v2.0
- **Isolation Type:** Optical
- **Isolation IC:** LTV814 x3
- **Display:** LED
- **Output Rule:** Output is AND with all three phases
- **Power Supply:** 3.3V
- **Active Level:** Low
