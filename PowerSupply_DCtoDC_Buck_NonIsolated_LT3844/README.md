## Buck DC-DC Converter, Based on LT3844
Note: v1.0 is a default applications from LTspice.  
Note: An exercise to understand the DC-DC converter.  

### Features, v1.3
- **Output:** 5V/100W
- **Input:** 12V
- **Controller:** PWM controller based on LT3844
